# SayLedger

Voice-first travel expense tracker with shared trips, bill splitting, balances, custom categories, and multi-currency support.

## V2 scope

- Voice and manual expense entry
- Trips and personal ledgers
- Invite friends to shared trips
- Paid by / Split with
- Equal, exact, percentage, and shares splitting
- Net balances and settle-up
- User-defined categories
- Multi-currency display
- Mobile-first PWA

This repository is the maintainable successor to the original SayLedger prototype.
